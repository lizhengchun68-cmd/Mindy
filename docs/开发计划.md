## 模块依赖

```
main → config → reader → transformer → writer
         ↓
    country_map.yaml / rules.yaml
```

## 验收标准

1. 17 行输出（20 行输入、合并重复订单号）
2. A 列美国=`服装专线`，其他=`国际电商专递CD（普货）`
3. B 列 `E-MMDD-订单号`；E 列预置国家简码
4. `4069983558` 4 商品 → 97 列，品名 4 扩展列存在
5. O 列备注不出现在输出中
6. 单元测试全部通过

## P9 运行评估（2026-06-06）

**输入**：`file/20260606.xlsx`（20 行）  
**输出**：`production/20260606.xlsx`（17 行、97 列）

| 检查项 | 设计文档要求 | 结果 |
|--------|-------------|------|
| 行数 | 合并重复订单号 → 17 行 | ✅ 17 |

| B 列 | `E-0606-{订单号}` | ✅ 全部符合 |
| E 列 | 预置国家简码（CA/FR/US） | ✅ |
| M/N 列电话 | 联系方式或 `6479375666` | ✅ |
| Z/AA | `否` / `USD/美元` | ✅ |
| 空列 | C/K/H/I/O–Y/AB–AF 等留空 | ✅ |
| 备注 | O 列备注不输出 | ✅ 输出无备注列 |
| 合并 | `4069983558` 4 子商品 → 1 行 4 槽位 | ✅ |
